# Back-End Development Capstone

## Project Description

This project is the Back-End Development Capstone Project. It combines backend services and a Django application into a complete backend solution.

## Environment Setup

This project was created from the provided coding project template.

### Python Version

Python 3.9.x

### Virtual Environment

The virtual environment used for this project is:

backend-capsule-venv

### Setup Script

The project setup was successfully executed using:

bin/setup.sh

The setup script installs the required dependencies and prepares the Python environment for the project.

## Running the Application

Install the required dependencies and run the Django application using:

python manage.py runserver

## Testing

Run the project tests using:

pytest

## Project Components

- Pictures microservice
- Songs microservice
- Django backend application
- REST APIs
- Database integration
- Containerized deployment
